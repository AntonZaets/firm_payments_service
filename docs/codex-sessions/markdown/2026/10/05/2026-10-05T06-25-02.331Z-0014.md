## Assistant — 2026-10-05T07:14:31.733Z

## Assistant — 2026-10-05T07:15:44.302Z

**Yes, using an exported lockfile—but not `uv.lock` directly.** Export it to the standalone `pylock.toml` format:

```sh
# On the host, with pyproject.toml present:
uv export --locked --format pylock.toml -o pylock.toml

# In Docker, only pylock.toml is needed for installation:
uv pip sync --system pylock.toml
```

Then launch with `python`, rather than project-based `uv run`. [uv documentation](https://docs.astral.sh/uv/concepts/projects/layout/#the-lockfile)

For this repo, copying both existing files is simpler: exporting adds another artifact to keep current.
